# 🌌 Galaxy Launcher

> **Next-generation, modern, cosmic-themed Minecraft launcher for Premium & Cracked players with complete instance isolation, Modrinth marketplace, 3D skins, and seamless auto-updates.**

---

## ✨ Features

- 🌌 **Cosmic Visual Engine**: 5 dynamic themes (*Nebula Purple*, *Supernova Cyan*, *Solar Flare Gold*, *Deep Void Obsidian*, and *Emerald Aurora*) with interactive starfield shaders & UI audio.
- ⚡ **Full Instance Isolation**: Isolated mods, configs, saves, shaders, and resource packs for every profile.
- 🧩 **Supported Mod Loaders**: Fabric, Forge, NeoForge, Quilt, and Vanilla.
- 🛸 **Integrated Modrinth Hub**: Search and 1-click install over 100,000+ mods, shaderpacks, and modpacks.
- 👤 **Accounts & 3D Skin Studio**: Supports Microsoft (OAuth) and Cracked (Offline) accounts with a real-time Three.js 3D character viewport.
- ☕ **Smart Java Matching**: Automatically routes Java 8, 17, or 21 according to Minecraft version rules.
- 🔄 **Automated Updates**: Silent background updates powered by `electron-updater`.

---

## 🛠️ Development & Building

```bash
# Install dependencies
npm install

# Run in Electron development mode
npm run dev

# Build production bundle
npm run build

# Build Windows NSIS setup installer (.exe)
npm run dist
```
