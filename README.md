# 🌌 Galaxy Launcher (v1.0.4)

> **Next-generation, modern, cosmic-themed Minecraft launcher for Premium & Cracked players with complete instance isolation, Modrinth discovery hub, 1-Click Instance Share Codes (GLX-XXXX), Free Galaxy Capes & Cosmetics Wardrobe, 3D Skin Studio, and seamless auto-updates.**

---

## ✨ Features

- 🔗 **1-Click Instance Share Codes (`GLX-XXXX`)**: Generate short shareable codes (e.g. `GLX-7749`) or portable encrypted base64 payload strings to clone and export instances, mods, loader settings, and configs to friends in seconds.
- ✨ **Free Galaxy Capes & Cosmetics Wardrobe**: 100% free exclusive animated Cosmic Capes, Void Wings, and Starlight Halos for all Galaxy players with real-time Three.js 3D character physics.
- 📦 **In-Place Add Content Engine**: Direct `+ Add Mods`, `+ Add Shaders`, and `+ Add Resource Packs` modals with clean, responsive emoji buttons (`📥`, `ℹ️`, `🗑️`, `✅`) that never glitch or overflow on any window size.
- 🌌 **Cosmic Visual Engine**: 5 dynamic themes (*Nebula Purple*, *Supernova Cyan*, *Solar Flare Gold*, *Deep Void Obsidian*, and *Emerald Aurora*) with interactive starfield shaders & UI audio.
- ⚡ **Full Instance Isolation**: Isolated mods, configs, saves, shaders, and resource packs for every profile.
- 🧩 **Supported Mod Loaders**: Fabric, Forge, NeoForge, Quilt, and Vanilla across all Minecraft versions.
- 🛸 **Integrated Modrinth Hub**: Search and 1-click install over 100,000+ mods, shaderpacks, and modpacks.
- 👤 **Accounts & 3D Skin Studio**: Supports Microsoft (OAuth) and Cracked (Offline) accounts with a real-time Three.js 3D character viewport, skin library, and IGN search.
- ☕ **Smart Java Matching**: Automatically routes Java 8, 17, or 21 according to Minecraft version rules.
- 🏆 **Cosmic Achievements Engine**: 12 in-launcher achievements with XP progression from *Stargazer* to *Cosmic Overlord*.
- ☁️ **Galaxy Cloud Sync & Network**: Secure cloud backups for instance configurations, worlds, and settings with friend presence.
- 🔄 **Automated Updates**: Silent background updates powered by `electron-updater`.
